# Τα Μαθήματά μου

Εκπαιδευτική εφαρμογή Streamlit για πολλαπλά μαθήματα. Η καρτέλα Αγγλικών
χωρίζεται σε Λέξεις και Γραμματική, με πρώτη γραμματική ενότητα τα
`would rather / sooner` και `would prefer`, με οπτικά παραδείγματα και εικόνες
μέσα στις σχετικές ασκήσεις. Περιλαμβάνεται επίσης διαδραστικό
μάθημα Ιστορίας για την Ελληνική Επανάσταση (1821–1827): διαδραστική αποστολή
παρατήρησης εικόνων, θεωρία, χρονογραμμή, κατανόηση και κριτική σκέψη.
Περιλαμβάνεται ακόμη μάθημα **Νεοελληνική Γλώσσα & Έκθεση** με τράπεζα
θεματικών ενοτήτων, διαδραστικό σχεδιάγραμμα και αυτοέλεγχο πριν από το πρώτο
προσχέδιο.

Το μάθημα **Χημείας** παρουσιάζει ενεργειακές στάθμες, τροχιακά, άτομα,
μόρια, ιόντα και χημικούς δεσμούς με διαδραστικά μοντέλα. Η παράσταση του
`H₂O` διαχωρίζει την περίπου τετραεδρική διάταξη των τεσσάρων περιοχών
ηλεκτρονιακής πυκνότητας από τη γωνιακή μοριακή γεωμετρία `H—O—H`, με γωνία
περίπου `104,5°`.

## Τοπική εκτέλεση

```bash
python3 -m pip install -r requirements.txt
streamlit run app.py
```

## Streamlit Community Cloud

1. Ανέβασε το repository στο GitHub.
2. Στο [Streamlit Community Cloud](https://share.streamlit.io) επίλεξε
   **Create app**.
3. Επίλεξε το repository, branch `main` και αρχείο `app.py`.
4. Πάτησε **Deploy**.

Η πρόοδος αποθηκεύεται τοπικά στον browser κάθε συσκευής. Για μεταφορά μεταξύ
Mac και κινητού χρησιμοποίησε την εξαγωγή και επαναφορά αντιγράφου JSON μέσα
από την εφαρμογή.
