# Τα Μαθήματά μου

Εκπαιδευτική εφαρμογή Streamlit για πολλαπλά μαθήματα. Η καρτέλα Αγγλικών
χωρίζεται σε Λέξεις και Γραμματική, με πρώτη γραμματική ενότητα τα
`would rather / sooner` και `would prefer`, με οπτικά παραδείγματα και εικόνες
μέσα στις σχετικές ασκήσεις. Περιλαμβάνεται επίσης διαδραστικό
μάθημα Ιστορίας για την Ελληνική Επανάσταση (1821–1827): διαδραστική αποστολή
παρατήρησης εικόνων, θεωρία, χρονογραμμή, κατανόηση και κριτική σκέψη.
Περιλαμβάνεται ακόμη μάθημα **Νεοελληνική Γλώσσα & Έκθεση** με τράπεζα
θεματικών ενοτήτων, διαδραστικό σχεδιάγραμμα και αυτοέλεγχο πριν από το πρώτο
προσχέδιο.

Το μάθημα **Χημείας** παρουσιάζει ενεργειακές στάθμες, τροχιακά, άτομα,
μόρια, ιόντα και χημικούς δεσμούς με διαδραστικά μοντέλα. Η παράσταση του
`H₂O` διαχωρίζει την περίπου τετραεδρική διάταξη των τεσσάρων περιοχών
ηλεκτρονιακής πυκνότητας από τη γωνιακή μοριακή γεωμετρία `H—O—H`, με γωνία
περίπου `104,5°`.

## Τοπική εκτέλεση

Στην έκδοση browser (`index.html`), η νέα ομάδα Αγγλικών **Σελίδες 66–70**
περιλαμβάνει 52 λέξεις από τις φωτογραφίες, ελληνικές σημασίες και πρωτότυπα
παραδείγματα με μετάφραση. Διαθέτει τεστ 10 ή 52 ερωτήσεων σε τρεις μορφές:
πολλαπλή επιλογή, συμπλήρωση προτάσεων και γράψιμο. Η πρόοδος αποθηκεύεται
τοπικά ανά λέξη, χωριστά από τις προηγούμενες ομάδες, ακόμη κι όταν μια λέξη
υπάρχει ήδη σε παλιότερη ομάδα.

Η ομάδα **Final Test 6 · Σελίδες 79–85** έχει τις ίδιες δυνατότητες με
62 διαφορετικές λέξεις και πλήρες τεστ 62 ερωτήσεων. Το `emerge`, που
εμφανίζεται δύο φορές στο υλικό, καταχωρίζεται μία φορά. Το 41β δεν είναι
ορατό στις φωτογραφίες και δεν έχει προστεθεί υποθετική λέξη στη θέση του.

Και οι δύο ομάδες ανοίγουν πρώτα σε διαδρομή μάθησης: λίστα λέξεων με
αναζήτηση και ελληνικές σημασίες → ιστορίες → κάρτες ανάκλησης → τεστ.
Οι σελίδες 66–70 έχουν 8 πρωτότυπες μικρές ιστορίες και το Final Test 6 έχει
9. Όλες οι 114 λέξεις εμφανίζονται ως πατήσιμες λέξεις στις ιστορίες της
δικής τους ομάδας, με ελληνική μετάφραση, προφορά μέσω του browser και
εξάσκηση μόνο στις λέξεις κάθε ιστορίας. Οι εικόνες σκηνών αξιοποιούν την
υπάρχουσα βιβλιοθήκη εικονογράφησης της εφαρμογής και δεν αποτελούν κυριολεκτικό
ορισμό κάθε λέξης. Από κάθε λέξη υπάρχει σύνδεση προς τη σχετική ιστορία.
Η προσθήκη ιστοριών είναι αυτόματη και διατηρεί την αποθηκευμένη πρόοδο.

Η **Ομάδα 5 / Final Test 6** διαθέτει επίσης 62 ξεχωριστά μνημονικά:
μια νοητή εικόνα, εξήγηση της σύνδεσης με τη σημασία και μια χρήσιμη φράση
ή παγίδα σύγχυσης. Ανοίγουν από τη λίστα ή πατώντας λέξη στην ιστορία.
Στις κάρτες εμφανίζονται μετά την αποκάλυψη και στα τεστ μόνο μετά την
απάντηση. Οι συνδέσεις επισημαίνονται ως μνημονικά, όχι ως ετυμολογίες.
Η ενημέρωση προσθέτει μόνο τα μνημονικά στις αποθηκευμένες λέξεις της
Ομάδας 5, χωρίς να μηδενίζει πρόοδο, βαθμολογίες ή προσωπικές εικόνες.

Όλες οι εκφωνήσεις Αγγλικών (λέξεις και ιστορίες, σε όλες τις ομάδες)
χρησιμοποιούν πλέον **American English (`en-US`) με γυναικεία φωνή**.
Το `assets/english-speech.js` προτιμά αναγνωρισμένες γυναικείες φωνές των ΗΠΑ,
με πρώτη τη Samantha, και περιμένει έως 2,5 δευτερόλεπτα όταν ο browser
φορτώνει τη λίστα φωνών. Πάτημα στη λέξη ή στο 🔊 ξεκινά συνεχή επανάληψη,
με μικρή παύση 0,8 δευτερολέπτων ανάμεσα στις εκφωνήσεις. Δεύτερο πάτημα
στην ίδια λέξη ή στο ⏹ σταματά την επανάληψη. Άλλη λέξη αντικαθιστά την
προηγούμενη· δεν δημιουργείται ουρά εκφωνήσεων. Η ένδειξη και το κουμπί
διακοπής ενημερώνονται αυτόματα. Η επανάληψη σταματά όταν κλείνει η κάρτα,
αλλάζει η προβολή ή η εφαρμογή κρύβεται. Οι ιστορίες εκφωνούνται μία φορά.
Η επιλεγμένη φωνή φαίνεται στην κεφαλίδα του λεξιλογίου.
Το [Web Speech API](https://webaudio.github.io/web-speech-api/#speechsynthesisvoice)
δεν παρέχει ιδιότητα φύλου: η επιλογή βασίζεται στη γλώσσα και σε γνωστά ονόματα
φωνών, όχι σε αλλαγή του ύψους μιας ανδρικής φωνής. Αν δεν βρεθεί κατάλληλη
φωνή, εμφανίζεται οδηγία αντί να επιλεγεί σιωπηρά ανδρική ή βρετανική φωνή.
Οι διαθέσιμες φωνές εξαρτώνται από τη συσκευή και το πρόγραμμα περιήγησης.

```bash
python3 -m pip install -r requirements.txt
streamlit run app.py
```

## Streamlit Community Cloud

1. Ανέβασε το repository στο GitHub.
2. Στο [Streamlit Community Cloud](https://share.streamlit.io) επίλεξε
   **Create app**.
3. Επίλεξε το repository, branch `main` και αρχείο `app.py`.
4. Πάτησε **Deploy**.

Η πρόοδος αποθηκεύεται τοπικά στον browser κάθε συσκευής. Για μεταφορά μεταξύ
Mac και κινητού χρησιμοποίησε την εξαγωγή και επαναφορά αντιγράφου JSON μέσα
από την εφαρμογή.
